# Security Policy

## Supported versions

Security fixes are considered for the current development version on the default branch. Until a stable release is published, no separate maintenance or backport policy is promised for older commits or tags.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue or pull request.

Report security concerns privately using the contact options on the [maintainer's GitHub profile](https://github.com/ephpicman). Include the affected commit or version, the impact you believe is possible, and a minimal reproduction when safe to share. Avoid including secrets or other people's private data.

The maintainer will assess the report and coordinate any fix or disclosure. The project does not currently publish a response-time SLA or operate a bug bounty program. If you receive no response, follow up privately rather than publishing exploit details immediately.
